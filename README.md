## 🧪 Running a Test Network

node shines when you create your own private test environment:

1. **Open a command prompt** (search for "cmd" in your Start menu).
2. **Type** `TESTNET=true` and press Enter – This enables test mode.
3. **Type** `WORKFOLDER=/tmp/testnet` and press Enter – This sets a storage location.
4. **Type** `HTTP_IPV4=127.0.0.1` and press Enter – This binds to your computer only.
5. **Type** `HTTP_PORT=80` and press Enter – This sets the web port.
6. **Type** `./amadeusd` and press Enter – This starts your network.

Now you have a fully functional blockchain running on your PC!

## 🔧 Troubleshooting Common Issues

### Node won't start
- **Check your internet connection** – A stable connection is required.
- **Run as administrator** – Right-click the program and select "Run as administrator."
- **Disable antivirus temporarily** – Some security software may block new programs.

### Web interface doesn't load
- **Use a modern browser** – Chrome or Edge work best.
- **Clear your browser cache** – Then refresh the page.
- **Check the port** – Ensure port 80 is free (close other web servers).

### Transactions are slow
- **Wait a few seconds** – The network may be processing.
- **Restart the application** – Sometimes a fresh start helps.
